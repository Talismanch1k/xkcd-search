Данный проект представляет собой веб-интерфейс (Frontend) для сервиса поиска (Search Service). Он предоставляет пользователям доступ к поисковой бесконечной ленте (на основе комиксов XKCD) подобно TikTok, а также включает в себя панель администратора для управления базой данных и индексной информацией.

## Основной функционал

- **Главная страница (`/`)**: Главная страница.
- **Лента (`/feed`, `/feed/discover`)**: Отображение результатов поиска (по релевантности) и рекомендаций (рандомные комиксы).
- **Панель администратора (`/admin`)**:
  - Защищена авторизацией (сессии хранятся в памяти, с настраиваемым TTL).
  - Позволяет запускать процессы асинхронного обновления базы данных (`/admin/update`).
  - Позволяет удалять/сбрасывать данные (`/admin/drop`).
